# Live speed instrument / 实时速度仪表

## corner.50：Windows 顶部全局仪表

顶部仪表汇总本地 Codex 会话及子代理的输出，采用同一个 3 秒时间窗。
并行的 40 和 60 tok/s 合计为 100 tok/s，不除以任务数量。切换选中的
项目不再重置速度、60 秒趋势、刻度颜色或额度虹彩。右侧小读数显示
近 30 秒全局均速，标题旁显示生成和工具阶段的任务数量。

真实响应按请求区间折算窗口内贡献；生成中的估算优先采用该会话同模型
近期实测，再回退到其他会话同模型、其他 Codex 实测样本。估算保持明确
标记，响应完成后由真实贡献替换。任务停下后贡献自然退出窗口，全部
暂停时显示 0 和工具／待机状态；没有基线显示“建立基线”，部分任务缺
基线显示“部分待测”，不把未知算作已测得的零。

现代响应 ID 跨日志去重，子代理复制历史同时检查创建时间和 ordinal
继承边界。实际 token 小计是当前保留的最近 30 分钟有效计时样本（界面
标注“采样”）；峰值为最近 60 秒内三桶均速的最大值，不是全天统计。
不同会话缓存输入按 token 加权。下方任务活动／响应详情仍跟随选中会话。

复用日志增量读取：每 100ms 检查热日志，正常计算帧 500ms，新事件立即
失效缓存。近期 5 分钟有日志活动的会话参与扫描；最多 64 个热日志读取器、
16384 个去重响应，首次每轮初始化最多两个。启动未读完、读取失败或超出
覆盖上限时显示“部分采集”，不会将部分结果称为完整测量。采集心跳和
数据帧过期仍停止当前速度显示。此修改针对 Windows 原生角落面板；以下
单会话计算仍供原有会话详情和兼容路径使用。

## 接入与范围

沿用 HUD 的本地只读接入：Codex 会话目录和 SQLite 线程索引用于选中会话，
增量读取对应 JSONL 的生命周期、请求边界、工具完成和 token usage 元数据。
支持现代 `token_usage_record` 与旧版 `event_msg/token_count`，按响应 ID、
usage 指纹和累计计数去重。截断尾部恢复保留模型上下文，并过滤 fork 复制的旧记录。
历史重放仅补充速度参考和响应图，不重复增加本轮确认 token。

自动跟随优先选择最近发起的用户任务；较早任务的后台输出及内部子代理不抢占面板。
无法识别任务开始记录时回退到最新活动；也可在托盘按 ID 手动固定指定会话。

此版本的速度属于**面板当前选中的 Codex 会话**。它不合并所有终端、子代理或
Claude 会话，不接入 Agent Speed 服务，也不新增外部网络请求、AI 请求或计费估算。
没有输入/输出流的逐 token 时间戳时，无法测得真正的瞬时流式速度。

## 计算口径

- **实测请求速度**：`output_tokens / 请求时长`。请求开始或最后一个工具结果到
  usage 记账的耗时包含首输出等待，排除已明确标记的工具执行时间。
  最短时长 500 ms，超过 15 分钟或缺失/倒序边界不参与速度计算，确认 token 仍保留。
  不把 `reasoning_output_tokens` 再加到已经包含它的输出总数中。
- **3 秒窗口**：已完成输出按请求时段均匀分配；取最近 3000 ms 的重叠部分，
  除以 3 秒得到活动吞吐。进入工具阶段后，窗口内的实测部分自然排空到 0；
  生成中该值作为主数字。工具暂停和待机时改为保留上次真实响应的速度，标注“工具中·保留”或“上次实测”，避免把活动窗口排空误当作新的零速测量。
- **主数字**：生成中显示当前 3 秒实测/估算窗口；有估算贡献时明确标注“实时估算”。上次实测在右侧独立保留。最近 30 分钟最多 10 次响应的加权均速仍保留为内部参考，不再覆盖正在变化的当前速度。没有有效样本时显示 `—`；估算不进入已确认 token。
- **实时估算**：仅在明确的活动生成阶段，且请求边界有效、最近活动不超过
  5 分钟时启用。基准优先取同会话、同模型最近 10 分钟的 3 个实测响应，
  否则取 30 分钟内最多 10 个响应；`Σ输出 / Σ请求时长`，不平均各响应的速率。
  没有基准就显示建立基线。工具阶段不预测新输出。
- **完成校准**：真实 usage 到达后替换该请求的估算。估算从不进入本轮输出、
  会话累计输出或峰值。峰值是保留的最近 30 分钟实测响应中的最高请求均速。
- **缓存命中**：最近最多 10 次有效响应的 `Σ缓存输入 / Σ输入`，按输入 token 加权。
- **60 秒速度趋势**：一秒一个点，实测实线、估算虚线；两者均按该段速度着色，所有点的单位均为 tok/s。
  最新不足一秒的采样按实际覆盖时长折算；整秒边界不插入没有观测的零值点，
  避免恒速生成时线头每秒假下坠。真实暂停仍会回落。这些速度点不能相加充当 token 总数，
  也不宣称是逐 token 实时采样。

采集器每 100ms 检查所选日志的增量；新事件会立即使计算缓存失效并发布，常规时钟帧为 500ms，原生界面每 100ms 接收数据。这与 Agent Speed 的 100ms 变化发布 / 500ms 常规帧对应；日志本身何时写入由客户端决定，不宣称逐 token 流式测速。独立动画时钟只影响外观。采集心跳超过 6 秒、
计算帧超过 3 秒、来源回放未完成或会话绑定不一致时，仪表停止展示当前读数。
区间选择保留区间均速并明确标识，不把它称为实时速度。

## corner.47 连续运动

仪表采用内凹金属细边和内圈流光。连续积分相位随真实速度平滑加减速，
避免 `时间 × 当前速度` 在变速时造成位置跳变；恢复绘制时限制单步时间。
36 段刻度按小数热度渐亮；工具暂停时能量收敛。完成响应沿边扫光 1.4 秒。
真实趋势增加淡色面积及端点提示，数字、坐标和实测/估算分类保持不变。
节点延迟、倒计时、响应读数与活动状态共用已有切换动画；首次、缓存和
不可用状态不会回放旧值。静态偏好与内存保护继续优先。

## 展示与动效

400 × 722 逻辑像素卡片将全局速度、会话平均响应和上下文放在首组，额度和重置雷达
合并在第二组，AI 服务与上网节点位于底部。小屏会按工作区自适应缩放。

36 段仪表使用 `heat = min(1, 速度 / 满刻度)` 控制点亮段数，默认满刻度为 300 tok/s。
200 tok/s 起进入流动光谱，降至 195 以下退出，以避免边界闪烁。超过量程仍显示真实数字。
主数字、上次实测和趋势按绝对速度从青蓝变为蓝紫、兰紫、玫瑰和琥珀金。已亮刻度由靠近起点的冷色渐变至当前速度对应的色调。

生成中，在最近 1.6 秒内相对较低读数上升至少 20% 且增加至少 4 tok/s 时，仪表出现追光、火花和增量读数。扫光持续 1.45 秒，两次反馈至少间隔 1.8 秒。首次读数、会话切换、工具阶段和静态模式都会重新建立比较起点。实时估算继续显示来源标记。
解析临界阻尼弹簧分别平滑刻度热度与主仪表颜色，颜色不受用户满刻度选项影响；数字的目标始终是计算值：变化的位按升降方向作 260ms 滚动，状态/位数改变采用固定位置交叉淡入淡出，后来的数据替换未完成动画，不排队也不编造中间计数。新会话/模型直接切到对应读数，首屏不从零虚构计数。
下方额度虹彩绑定相同的主数字读数，以 `1/18 + (0.4 - 1/18) × (1 - exp(-速度/65))` 得到每秒循环数；有效重置预告时乘 1.25，最高每秒半圈。
连续相位积分和 0.65 秒速度缓动避免更新时跳色，暂停后最多补偿 250ms；静态或低内存时冻结相位。
生成期间环内彗星随热度加快；新实测响应触发 1.4 秒双层波纹，首次加载和切换会话不提示旧完成。
托盘可调整满刻度，默认 300 tok/s，重启保留。
静态模式保持真实值、颜色和估算标签，关闭装饰性运动。

雷达原有截止日期、信号高亮与去重系统通知继续独立工作，仪表不额外播放声音或发送通知。
文档中的动图使用测试数据；实际桌面读数来自本地采集器。

速度、上次实测、缓存、周额度、近期消耗速度与今日建议数字共享上述过渡机制。仅短过渡期间提高动画时钟至 16ms，其余动态为 40ms；静态偏好和内存保护立即显示最终值。趋势横坐标按采样时间连续移动，纵轴以临界阻尼弹簧平滑调整。所有绘制均为局部矢量，无新增位图缓存或后台线程。

加速与输出完成的反馈只绘制在全局输出内卡的圆角裁剪区域，下方响应和上下文不参与闪光。
彩虹扫光使用约 13.5° 的轻微倾斜、八段羽化渐变和较低透明度，按平滑曲线进出；
原有 1.45 秒触发时长与去重规则保持不变。首组外框保持稳定，不再随输出加速整体发光。
