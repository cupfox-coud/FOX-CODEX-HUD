# Graphite Glass / 石墨玻璃

面板优先回答四件事：还剩多少额度、是否有重置预告、两条线路是否正常、当前响应如何。
400×536 逻辑像素的原生卡片使用 24 像素外边距、12 像素双卡间距、26/18 像素圆角层级。
Segoe UI 与 Microsoft YaHei UI 使用本机字体。数字与中文标签分开控制字号，截止日期按长度适配。

石墨底色以低强度蓝、薄荷环境光增加层次；内容表面保持深色，边缘使用细渐变。
暖金只提示有效的预测，橙色表示临近或变慢，薄荷表示正常或已确认的公共重置。
主数字不插值；延迟柱图、响应曲线只来自真实采集值。

| 触发 | 视觉反馈 | 时间 |
| --- | --- | --- |
| 新预告、预告变更、已确认重置 | 外缘强调、卡内扫光、扩散环、系统通知 | 强调 12 秒，通知去重 |
| 日常运行 | 缓慢移动的环境光、玻璃边缘反光、无预告时蓝色扫描 | 装饰性动效不代表新信号 |
| 持续有效预告 | 轻呼吸与雷达环 | 信号有效期间 |
| 线路状态变化 | 颜色平滑过渡、对应线路提示 | 700 ms 过渡，提示 8 秒 |
| 新的线路测量 | 卡片边缘与内层亮起、状态点扩散、下沿强调 | 2.4 秒 |
| 新完整响应 | 曲线与坐标范围同步过渡、端点扩散 | 900 ms 过渡，1.8 秒端点反馈 |
| 活动进行中 | 状态点、时钟、曲线上少量流光 | 只在活动状态 |

动画定时器 25 Hz，远程会话 10 Hz。托盘打开时暂停额外动画，默认跟随 Windows 设置；托盘“面板动效”可显式开启完整动效或选择静态显示，选择保存后重启仍有效。
底色、细颗粒和两张柔光位图缓存一次，动态画笔、路径和字体按生命周期释放；动画不读文件、不探测网络、不播放额外声音。

参考：[Apple HIG Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、
[Motion](https://developer.apple.com/design/human-interface-guidelines/motion)、
[Typography](https://developer.apple.com/design/human-interface-guidelines/typography)，
以及 [DevSam7t3/liquid-glass](https://github.com/DevSam7t3/liquid-glass) 对边缘高光和材质分层的探索。
此版本在现有 WinForms/GDI+ 绘制器中独立实现，没有引入该网页项目的代码、字体或依赖，
也没有实现屏幕内容折射。示例截图与动画使用模拟数据，真实运行仍由本机采集器驱动。
