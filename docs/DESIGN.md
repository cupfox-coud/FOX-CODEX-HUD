# Quiet Graphite / 静谧石墨

corner.47 将逐步增加的功能整理为一张可扫读的桌面仪表。400×738 逻辑像素保持不变，所有内容表面使用 20 像素外边距、16 像素内边距和 18 像素圆角；外壳圆角为 26。主体区之间留出 12 像素，辅助标签不再各自嵌套小卡片。

## 材质、字级与颜色

石墨背景使用缓存细颗粒与低强度蓝、薄荷环境光。内容表面为中性深色渐变，常态边缘只保留细描线。颜色承担具体状态：薄荷表示充足/健康，暖金表示预告，橙色表示提前耗尽或临近，玫红表示紧急或失败。普通响应曲线统一为柔蓝，端点保留最新响应的延迟颜色。

超额警告采用 #090B0F 墨黑内嵌表面、#E2BE7E 琥珀金属边和 #FFEED0 暖白负数。第一栏保持原有尺寸，斜面反光与沿边框游走的高光形成独立提醒；其余数据保持清晰，避免整卡大面积红色或数字闪烁。

鲜活且大于零的周额度百分比采用柔和流动虹彩，包含 `%` 符号；字体轮廓、位置和真实数值保持不变。流动速度直接绑定上方显示的输出速度（近期实测均速，或有效实时/区间读数），用连续相位和 0.65 秒时间常数平滑加减速；不会因速度变更突然跳色。无有效速度时约 18 秒一轮，12 / 48 / 160 tok/s 时约 8.8 / 4.3 / 2.7 秒一轮。明确属于全局额度重置的公开预告有效时增强饱和度、再提高 25% 流速，最快约 2 秒一轮；标题改为“周额度 · 优先使用”。整块额度表面、边缘、标题、数字、时间轴共用同一流动相位。空窗仍使用斜线纹理和虚线底轴，日期与预计用尽位置保持固定。额度面板与雷达通过上行光点联动，新预告、变更或临近事件沿用已有去重时钟，前 12 秒增加向上扫光及边框强调，之后保留与输出速度联动的沿边高光。没有增加卡片高度或新的常驻控件。

网站确认全局额度重置时，额度区以薄荷色反馈 12 秒，并提示“核对到账”；不继续鼓励消耗，也不把公开记录等同于个人额度已恢复。雷达离线、过期或无预告时停止联动，账户仍有鲜活余额时保留平常虹彩。账户缓存和未知余额保持中性，实际余额为零保留警告色；静态模式和低内存时保留静态渐变与明确文字，停止所有新增动态。

重置雷达按 API 的 `reset_type` 区分事件效果，不从“有排期”、时间精度或公告标题猜测类型：

| 类型 | 雷达呈现 | 对周额度的反馈 |
| --- | --- | --- |
| `global` | 全局额度重置；暖金预告、薄荷完成记录 | 有效预告提示优先使用并增强虹彩；完成记录短暂提示核对到账 |
| `banked` | 紫色“重置卡发放”，常驻“不自动重置额度”；完成后显示“重置卡已发放” | 保持日常额度状态，不提示提前清空、不增强虹彩、不提示额度到账 |
| `global_and_banked` | 明确显示“重置＋发卡” | 因明确包含全局重置，保留额度联动 |
| 缺失或未知 | 类型未明；不推断为全局重置 | 不触发清空建议或额度恢复提示 |

两类事件均保留 API 的截止日期、倒计时和时间窗口含义。系统通知从标题到正文均说明事件类型，发卡及其临近提醒明确无需提前清空额度。事件类型纳入预告变更识别，同一事件更改类型时更新一次；不相关事件的通知不会改变当前雷达或额度的动画含义。新界面保持 400×738 尺寸与既有布局。

字体全部来自本机 Segoe UI / Microsoft YaHei UI。速度主值 38px、额度 48px、预计可用时间 21px，次指标 18px、标题 12px、说明 10–10.5px。小字由原先 9px 提高到 10px，次要文字色为 #B6C1D0。以最亮内容表面 #212833 计算，78% 面板不透明度叠在纯白桌面上的次要文字对比度约 4.59:1；更低用户透明度及悬停淡化不保证相同对比度。

周额度按最新官方快照与当前时间实时重算，详见 [QUOTA_RUNWAY.md](QUOTA_RUNWAY.md)。百分比、可用时间和速度主数字不插值。电池充填宽度与内部百分比共同呈现实际余额；下方改用 328px 宽的开放时间轴，去掉圆头胶囊和实心填充条。左端为现在，右端为官方重置，范围内只展示未来时间。超过 36 小时使用真实本地午夜日期刻度，短窗口使用整点小时刻度；标签相撞时省略部分标签，刻度位置始终按真实时间计算。预计用尽位置以细竖线和三角标记标出，约略用尽日期在右侧预计可用时间下方注明；右端保留官方完整日期时间。

常态可用时段沿用薄荷细线与淡底色；用尽后至重置的空窗区使用暖金斜线纹理、虚线底轴和“预计空窗 × 天 × 小时”图例。斜纹缓慢移动，每 4.8 秒平移一格，事件节点、日期、数值及时间轴几何位置保持静止。静态模式及低内存时保留完整斜纹；缓存使用灰色纹理和“上次”标注，并停止移动。没有预测时保留时间坐标和待估算文字，不绘制预测区间。预计足够时使用完整薄荷细轴及“预计无空窗”。只使用现有字体、石墨材质和矢量绘制，不增加组件高度。

下方三列的中心点为 84、200、316px；标题分别居中。数值和 `%` / `%/天` 先按实际字体测量，再作为一个整体居中，短数值、负数和缺失占位符沿用同一对齐方式。超额墨黑小栏仍以第一列中心对齐。

仪表增加内凹石墨表面、金属细边与内圈流光；所有卡片共用窄幅内倒角及顶部反射。仪表亮段按小数热度渐亮，彗星通过积分平滑角速度移动，不因速度变更跳位置。工具阶段逐渐收敛能量；真实响应完成沿仪表边缘扫光 1.4 秒。趋势底部仅增加低透明度面积与实测端点，不改变真实曲线。

节点延迟、雷达倒计时和平均响应加入同一套 260ms 数字切换；最新线路采样在 420ms 内展开。真实额度扣减以蓝色细边反馈 1.1 秒；账户真实补额以薄荷边缘反馈 2.6 秒。首次加载、相同快照、迟到快照不重播；公共发卡不能触发个人到账反馈。新增绘制复用现有时钟，低内存/静态模式停止运动。

## 动效分工

| 触发 | 反馈 |
| --- | --- |
| 待机 | 低强度环境光与雷达图标扫描；扫描不表示发现新信号 |
| 生成 | 仪表热度平滑跟随、彗星；主数字及已亮刻度随绝对输出速度由青蓝过渡至蓝紫、玫瑰与琥珀金；完成响应时局部波纹 |
| 新预告、变更、确认重置 | 雷达横条扫光、扩散环及外壳强调 12 秒，原有去重系统通知 |
| 平常有效余额 | 周额度百分比和符号柔和虹彩流动；跟随上方显示速度平滑加速、减速，数字位置固定 |
| 有效全局重置预告 | 雷达与额度区上行光点联动、整块表面及时间轴增强虹彩、优先使用提示；到达前 12 秒加强扫光与边缘，未变更轮询不重复触发 |
| 公开确认全局重置 | 额度区短暂薄荷色反馈并提示核对到账，不假设个人额度已恢复 |
| 持续有效信号 | 雷达局部低强度呼吸；预告期间额度区保持随速度流动的沿边高光 |
| 今日超额 | 4.4 秒斜向反光、细边呼吸和边缘游光；超额越多边光适度增强；缓存、静态模式及低内存时不动 |
| 提前耗尽 | 空窗区以斜纹慢移和直接标注的时长提示，4.8 秒移动一格；日期节点、数值及时间轴几何位置保持静止；缓存、静态偏好及低内存时保留静止斜纹；仅剩约 6 小时或已耗尽时加强卡片反馈 |
| 线路变化/采样 | 独立颜色过渡和状态点反馈；故障保留局部提示，正常不再整卡闪光 |
| 新完整响应 | 900ms 曲线形变、1800ms 端点反馈；曲线和纵轴同时过渡 |
| 鼠标悬停 | 保留穿透时的 180ms 淡化，离开恢复用户不透明度 |

复用现有 25Hz 时钟，远程会话 10Hz，托盘菜单打开时暂停额外动画；支持系统偏好、显式完整动效及静态模式。没有新增计时器、网络请求、字体下载或渲染框架。GDI+ 资源按生命周期释放；内存紧张时释放缓存并以每秒一次的静态绘制保留信息，恢复稳定 30 秒后再恢复原设置。

## 实时数值过渡

新数值以 260ms 的出场减速滚动到位，只移动变化的数字位；位数、正负号和状态发生变化时，在固定槽位交叉淡入淡出。目标始终是实际计算值，不逐项编造中间读数，不重播同值，新数据到来立即接管。仅短过渡期间启用 16ms 动画帧，其余沿用 40ms；初次加载、会话/模型切换、余额失效/耗尽及低内存、静态模式直接到位。图表按采样时间滚动，纵轴平滑跟随数据范围。
