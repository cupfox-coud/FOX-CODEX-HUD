# Quiet Graphite / 静谧石墨

当前 Windows 角落卡片为 400 × 722 逻辑像素，遵循原有三组结构；小屏按工作区缩放。石墨半透明表面、细边框与克制的局部光效保持统一，不用动画改变数据位置。

## 阅读层级

| 区域 | 内容 |
| --- | --- |
| 顶部 | 全局输出速度仪表、30 秒均速、缓存命中及 60 秒趋势 |
| 第一组下部 | 当前会话平均响应与上下文占用；70% / 85% 提醒 |
| 第二组 | 左侧周额度与官方刷新倒计时，右侧近期消耗速度和今日建议 / 超额；下方公共重置雷达 |
| 第三组 | AI 服务与上网节点的独立延迟及采样 |

额度右侧为开放式双列，标签、数字与说明对齐。单位与数字共用基线并占据固定位置；超额以羽化墨黑底和琥珀底线提示。上下文和响应使用内凹细边界，与同组速度仪表保持清楚区分。

## 动态表现

输出颜色随实际速率变化；默认量程 300 tok/s，200 tok/s 以上进入彩色流动光谱。明显加速时使用柔和倾斜扫光，只裁剪在全局输出区域；响应与上下文不受加速特效影响。周额度虹彩随速度平滑变化，明确的全局额度重置预告才增强额度联动；发卡使用独立紫色提示，不暗示额度自动刷新。

真实数值变化使用短过渡；状态变化、缓存与不可用信息有独立标签，不制造采样。超额与上下文提醒保留静态识别，减少动画或内存保护时停止装饰性运动。重绘与资源检查覆盖动画边界和受限内存状态。
